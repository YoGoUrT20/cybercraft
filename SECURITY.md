# Security

CyberCraft runs native code inside Cyberpunk 2077, shares memory with a Minecraft process on the
same PC, and lets friends join a Minecraft world over the internet. If you find a way for another
player, a shared world or another process to crash the game, read memory it shouldn't, or run code
on someone's PC, please report it privately rather than in a public issue:

**[Report a vulnerability](https://github.com/YoGoUrT20/cybercraft/security/advisories/new)**

Include what you did, what happened and the CyberCraft version. Only the latest release gets fixes.
